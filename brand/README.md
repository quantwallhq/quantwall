# QuantWall brand kit

Use these files so the channel, the repo and every page look like one thing.

| File | Use |
|---|---|
| `avatar.svg`, `avatar_800.png` | Profile picture (square, shown as a circle) |
| `banner.svg`, `banner_2560x1440.png` | YouTube banner (content inside the centre 1235 x 338 safe area) |
| `logo_wordmark_dark.svg`, `logo_wordmark_light.svg` | Horizontal wordmark on dark and light backgrounds |
| `colors.json` | Palette tokens |
| `channel_text.md` | Channel name, handle, tagline, description, contact, links |
| `templates.md` | Video description, pinned comment and standard reply templates |

## Wordmark

"Quant" in the foreground colour, "Wall" in red (`#F85149`). Bold monospace. Never stretch, recolour or add effects.

## Type

One family everywhere: **DejaVu Sans Mono** (Menlo is the fallback on a Mac). Titles in sentence case, bold, top-left.

## Colour rules

- Dark background `#0D1117` is the default surface.
- Blue is the subject, green is a real edge or a pass (always paired with a check mark), red is a failure or danger (always paired with a cross), amber is the highlight.
- Thumbnails: no arrows pointing at money, no profit figures, no rockets or cars.

## Name and tagline

**QuantWall** (one word, capital Q and W). Tagline: **NO BLACK BOXES · NO HYPE**.
